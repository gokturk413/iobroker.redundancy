Which instances follow the primary

cold: runs only on the primary; on a switch it moves there and starts (any adapter, a few seconds). hot: runs on every server, only the primary writes; the adapter must hold back on the standby (its io-package says common.redundancy.hot). Until the hosts can run one instance on every server (H3), a hot instance moves like a cold one. none: stays on its host (admin, web, …). A serial line or RTU over TCP takes only one master: keep such an instance cold. Saving a mode restarts that instance.

A critical instance fails when its health signal stays bad (N readings in a row, or for the detect time) or it is not alive; it counts as recovered only after the recover time of good. move whole primary: when 2 critical instances fail on the primary (RFC-003 §2.11a), its watchdog switches to the standby — only if the standby checked out, outside the 60 s hold, at most 2 an hour, never under the maintenance lock, never to a server in a worse state. alarm only: an event, no switch. Check B: probe = the standby opens a TCP connection to the device every 5 s (nothing is sent); if it cannot reach the device either, it is a field problem and nothing moves. Do not probe a gateway that takes only one client (RTU over TCP): choose none. Health is sent to the watchdog with the API token of this instance's settings.

SyncObjects, states and files are replicated by Redis all the time. This copies what Redis does not hold.

                Failover timing
                

                
Built in: no automatic failback (an operator switches back), 60 s hold after a switch, at most 2 automatic switches per hour; the maintenance lock stops every automatic switch.

            

            

                Redis client options on every host
                
Checked in each host's iobroker.json (objects and states). Without them a switch costs seconds more, or js-controller stops.

                

            

            

                Heartbeat links
                
Any medium that carries UDP. The peer counts as lost only when every link is lost and the witness agrees; use at least two independent links.

                

            

            

                Client address (VIP)
                
A virtual IP that follows the primary comes in a later version (H4). Until then clients reach the primary through Sentinel (ioBroker hosts) or by its own address.

            

            

                Licence
                
One key for the whole cluster: it lists the hardware ids of every server. Each watchdog checks it itself. Without a key the trial runs 14 days; after that the watchdogs stop (no failover, no fence).
