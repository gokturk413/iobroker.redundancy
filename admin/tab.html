Which instances follow the primary

cold: runs only on the primary; on a switch it moves there and starts (any adapter, a few seconds). hot: runs on every server, only the primary writes; the adapter must hold back on the standby (its io-package says common.redundancy.hot). Until the hosts can run one instance on every server (H3), a hot instance moves like a cold one. none: stays on its host (admin, web, …). A serial line or RTU over TCP takes only one master: keep such an instance cold. Saving a mode restarts that instance.

Failover timing

Built in: no automatic failback (an operator switches back), 60 s hold after a switch, at most 2 automatic switches per hour; the maintenance lock stops every automatic switch.

Redis client options on every host

Checked in each host's iobroker.json (objects and states). Without them a switch costs seconds more, or js-controller stops.

Heartbeat links

Any medium that carries UDP. The peer counts as lost only when every link is lost and the witness agrees; use at least two independent links.

Client address (VIP)

A virtual IP that follows the primary comes in a later version (H4). Until then clients reach the primary through Sentinel (ioBroker hosts) or by its own address.

Licence

Not in this version: the redundancy engine runs without a licence key for now.

Instance settings of each server

Status file, API and API token of each server's redundancy instance.

    Switch over?

    What will happen
    1. Writes on the primary's Redis pause.
    2. The target waits until it has every byte; if it cannot catch up in time, nothing changes.
    3. Sentinel promotes the target's Redis; the old primary's Redis becomes its replica at once.
    4. Cold instances stop on the old primary and start on the new one.

    Run it hot?

    Hot runs the instance on every server at once; only the primary may write.

      Change the watchdog settings

      The same values on every server. Applied without a restart, under a maintenance lock, so that no automatic switch runs while the servers differ for a moment.
